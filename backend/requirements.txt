# Backend runtime dependencies.
#
# This file was a `pip freeze` of a vLLM training environment: 182 pins including
# torch+CUDA wheels, vllm, ray, pyspark and flashinfer. The backend talks to vLLM
# over HTTP and needs none of that — the freeze made the image many gigabytes and
# broke CPU-only installs. What follows is only what the served application
# imports. Regenerate by hand, not with pip freeze.
#
# torch is still required, transitively, by sentence-transformers for FAISS
# few-shot embeddings. Install the CPU build in the container (see
# backend/Dockerfile): ~200 MB against several GB for the CUDA build.
#
# The standalone research scripts under backend/data/*-Scripts/ import unsloth,
# trl, datasets, nltk and torch-cuda. They are not part of the service and are
# gitignored; install their requirements separately if you run them.
